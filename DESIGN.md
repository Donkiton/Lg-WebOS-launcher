# Прототип LG Home

Это история проектирования, включая ранние ограничения и параметры макета. Текущее состояние, размеры каталога, сборка IPK и установка Home/автозапуска описаны в [README.md](README.md). Упомянутые локальные журналы и снимки не входят в публичный репозиторий. Публичный `preview-catalog.js` содержит пять общих примеров; собственный снимок можно получить командой `node scripts/sync-tv-catalog.js`.

Основа — выбранный пользователем макет с горным закатом, часами слева и рядом из пяти выбранных приложений и «Все приложения». Сейчас проверяем прототип на ПК, без установки на телевизор. Интерфейс получает данные через адаптер платформы.

## Дизайн

- Холст 1920 × 1080, пропорциональное вписывание в окно с сохранением телевизионной композиции.
- Часы 106 px, дата 38 px, подписи карточек 26–30 px. Segoe UI / Arial.
- Карточки 270 × 204 px, радиус 23 px, промежуток 28 px. Выбранная карточка увеличивается в 1,13 раза и получает светло-голубое свечение.
- Анимации transform / opacity, 220 мс; быстрый режим 120 мс. Учитывается prefers-reduced-motion.
- Закатный фотографический фон, тёмные нижние края. Отражения карточек можно отключить.
- При первом запуске: по возможности установленные YouTube, Okko, RUTUBE, Иви, Zona либо Media Station X; затем «Все приложения». Пользователь может изменить состав и порядок. И в снимке для ПК, и на ТВ используются идентификаторы фактически установленных приложений. Сохранённый пользовательский выбор имеет приоритет над начальным набором.
- В основном экране отсутствуют боковое меню, рекомендации и ряд источников сигнала. Источники находятся в настройках.

## Поведение

1. Короткое OK / Enter / клик открывает приложение. Удержание OK 700 мс открывает меню: открыть, добавить / убрать с главного, изменить порядок. Отпускание после удержания не запускает приложение. На ПК меню также открывается правым кликом или M.
2. «Все приложения» показывает страницы по 15 карточек, три ряда по пять. Первые карточки первой страницы — избранные точно в порядке главного экрана, затем остальные в отдельном стабильном порядке. При пяти занятых местах добавление сразу предлагает выбрать одну из пяти карточек для замены. Заменённое приложение возвращается в базовую сортировку каталога.
3. Стрелка вверх → настройки / подключение; стрелка вниз возвращает к последней карточке.
4. Настройки меняют анимацию, отражения, затемнение и подсказки. Параметры хранятся в localStorage.
5. Escape / Backspace — назад; Home / H — главный экран; F — полноэкранный режим браузера.
6. Источники сигнала в телевизионной версии запрашиваются у webOS: количество, идентификаторы, названия (в том числе пользовательские, если доступны) и состояния подключения. Фиксированного списка HDMI или других входов в коде быть не должно. Список обновляется при открытии экрана; изменения подключений учитываются по доступным системным уведомлениям либо повторному запросу. При недоступности данных показывается соответствующее состояние без вымышленных входов.
7. Перестановка открывает отдельный ряд карточек, выбранная приподнята и подсвечена; стрелки ← → плавно сдвигают карточку и её соседей. OK сохраняет черновик, «Назад» отменяет. Мышью доступны кнопки стрелок, сохранения и отмены.
8. После изменения возвращаемся к исходному экрану. Состав и порядок хранятся отдельно от каталога; удаление с главного не удаляет приложение. Пользователь может оставить меньше пяти карточек. «Все приложения» доступно всегда.
9. «Настройки телевизора» — отдельный пункт в настройках лаунчера. Физическая кнопка настроек LG не перехватывается.
10. Вправо на правом краю строки — следующая страница в ту же строку первого столбца, влево на левом краю — предыдущая в последний столбец. На неполной странице позиция ограничивается существующими карточками. Верхняя граница первой страницы и конец каталога не зацикливаются. Счётчик с кнопками страниц показывается только при нескольких страницах. Запуск / возврат и действия с избранным восстанавливают фокус по ID приложения, включая его перенос на другую страницу.
11. Базовый порядок сохраняется независимо от избранного: существующие приложения не перемешиваются при новом ответе системной службы, новые добавляются в конец. Даты установки не выдумываются: первоначальный порядок соответствует первому ответу каталога. Убрано пояснение «место на главном экране» внизу; подсказки ПК отсутствуют в телевизионном режиме. Подсказки OK на ТВ зависят от настройки подсказок.

## Данные и ограничения проверки

`platform.js` выбирает браузерный поставщик или webOS по среде запуска. Браузерный поставщик читает `preview-catalog.js`: снимок настоящих launchPoints с телевизора, полученный командой `node scripts/sync-tv-catalog.js` по root SSH. Иконки скопированы в `assets/tv-apps/`. Случайных приложений в каталоге больше нет. Интерфейс не содержит фиксированного списка приложений, входов или статуса Wi-Fi. Сеть без доступа к ТВ показывается как недоступная. В webOS выполняются текущие Luna-запросы каталога, сети и входов; ошибки не подменяются снимком. Снимок и живой каталог используют общий нормализатор. Каталог обновляется при возврате фокуса / видимости страницы и открытии каталога, с ограничением частоты; сеть — также при открытии её экрана, входы — при каждом открытии. Подписки на изменения ещё не используются.

Общие настройки и карточки сохраняются в localStorage на текущем устройстве и origin. Браузерный и телевизионный списки карточек разделены. При заблокированном хранилище изменение карточек не подтверждается как сохранённое. Перестановка не записывает черновик до OK.

Адаптер webOS проверен тестовыми ответами служб; чтение списка launchPoints по root SSH на данном LG подтверждено. Разрешения LS2 обычного установленного приложения, производительность и системные переходы на LG ещё не проверены. Для каталога может понадобиться привилегированный сервис. Пакет IPK, автозапуск и перехват Home пока не созданы; на телевизоре выполнялось только чтение каталога и файлов значков. Отдельной Zona в каталоге нет; прежняя выбранная тестовая карточка мигрирует на установленный Media Station X с его настоящим названием. Остальные выбранные бренды также мигрируют на реальные ID без перестановки. Для сервисов с согласованными логотипами сохраняется оформление макета, остальные карточки показывают реальные PNG-значки и названия. Длинные названия ограничены двумя строками, полное название доступно в подписи доступности и title.

Фон восстановлен встроенным Image Gen из пользовательского изображения: удалены часы, иконки, карточки и их отражения; сохранены композиция гор, леса, озера и палитра заката. Исходный запрос генерации: «Standalone 16:9 wallpaper matching the approved reference; remove all UI and reconstruct the natural scenery; preserve mountains, forest, orange-pink sunset and dark lake; no text, logos or device frame».
