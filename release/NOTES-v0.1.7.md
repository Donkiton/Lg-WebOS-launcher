Готовый комплект LG Gate для самостоятельной установки на телевизор. Сборка приложения **0.1.7** с семью новыми фонами, миниатюрами и предпросмотром. Сам IPK сохранён побайтно из версии, установленной и проверенной на LG SM8200PLA 24 октября 2026 года.

### Что скачать

- **`lg-gate_0.1.7_install.zip`** — начните с этого файла. Внутри готовый IPK, команды настройки Home/автозапуска/Back, runtime и пошаговая инструкция. Сборка из исходников не нужна; для первоначальной настройки на компьютере нужны Node.js 20+ и OpenSSH.
- **`org.lggate.launcher_0.1.7_all.ipk`** — приложение отдельно, если инструменты уже настроены.
- **`dejavuln-autoroot-0.0.10.zip`** — тот самый USB-архив для получения root, использованный при подготовке проверенного ТВ. Это неизменённая копия [выпуска throwaway96](https://github.com/throwaway96/dejavuln-autoroot/releases/tag/v0.0.10), внутри Homebrew Channel 0.7.3. При уже работающем root он не нужен.
- **`INSTALLATION.md`**, **`ROOTING.md`** — установка, совместимость, подготовка флешки и откат.
- **`SHA256SUMS.txt`**, **`release-manifest.json`** — контрольные суммы; для USB-архива также сверено совпадение с upstream.
- **`ROOT-TOOL-NOTICES.md`**, **`dejavuln-autoroot-AGPL-3.0.txt`**, **`dejavuln-autoroot-0.0.10-corresponding-source.zip`** — атрибуция, лицензии и исходники сторонних компонентов с рецептами сборки. Это сопроводительные материалы, их не нужно устанавливать на ТВ.

### Совместимость и установка

LG Gate проверен только на **LG SM8200PLA · ПО 05.40.97 · webOS 4.10.2 (поколение 4.5) · Homebrew Channel 0.7.3 с root-сервисом**. Другая модель или прошивка требуют отдельной проверки. Возможность получения root проверяйте по своей модели/прошивке в [CanI.RootMy.TV](https://cani.rootmy.tv/); поддержка root не гарантирует поддержку лаунчера.

1. Если root ещё нет, прочитайте `ROOTING.md` и upstream-инструкцию перед использованием USB-архива.
2. Распакуйте установочный ZIP, откройте `README.md` и следуйте `docs/QUICKSTART.md`: SSH-ключ → установка IPK → проверка пульта/каталога → Home → автозапуск.
3. Сохраните комплект для отката. Перед удалением IPK отключите автозапуск и восстановите штатный Home.

После настройки приложение работает на телевизоре без запущенного сервера на ПК. При холодном включении возможен краткий показ Live TV до старта LG Gate.
