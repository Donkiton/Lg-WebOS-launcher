## Возможности

- До шести главных карточек: закрепление, замена и перестановка.
- Каталог приложений телевизора и поддерживаемые ярлыки Media Station X.
- Запуск по кнопке Home, автозапуск и возврат после выхода из приложения.
- Настройки анимации, отражений и затемнения; управление пультом и мышью.

**На пульте:** стрелки — навигация, OK — запуск, синяя кнопка — действия с карточкой, Back — назад.

## Установка на телевизор

Нужны **root-доступ и Homebrew Channel**. Получение root в комплект не входит.

Скачай IPK и следуй [пошаговой инструкции](docs/INSTALLATION.md): установка приложения → назначение Home → автозапуск. Там же описан полный откат перед удалением.

Проверено на **LG SM8200PLA · webOS 4.5 · прошивка 05.40.97 · Homebrew Channel 0.7.3**. Другие конфигурации требуют проверки.

## Посмотреть на компьютере

Нужен Node.js 18+.

```powershell
git clone https://github.com/Donkiton/Lg-WebOS-launcher.git
cd Lg-WebOS-launcher
npm start
```

Открой **http://127.0.0.1:4173**. На скриншотах выше — этот предпросмотр с общими примерами; на телевизоре каталог берётся из webOS. Установленный лаунчер работает без сервера на ПК.
