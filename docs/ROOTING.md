# USB-файл для получения root

Для проверенного телевизора использовался **DejaVuln Autoroot 0.0.10** от throwaway96. Это сторонний инструмент; LG Gate устанавливается после него отдельным IPK. Если Homebrew Channel с root уже работает, повторно получать root не нужно.

## Скачать нужный файл

- [Оригинальный выпуск DejaVuln Autoroot v0.0.10](https://github.com/throwaway96/dejavuln-autoroot/releases/tag/v0.0.10).
- [Прямая загрузка USB-архива](https://github.com/throwaway96/dejavuln-autoroot/releases/download/v0.0.10/dejavuln-autoroot-0.0.10.zip).
- Побайтная копия `dejavuln-autoroot-0.0.10.zip` также приложена к [релизу LG Gate v0.1.7](https://github.com/Donkiton/Lg-WebOS-launcher/releases/tag/v0.1.7) вместе с лицензией, атрибуцией и исходниками сторонних компонентов.

Размер ZIP — **1 700 171 байт**. SHA256:

```text
83f39e95ec702e6370df65bde16acced9861a87e473f763a9e55de948aa7756f
```

Это именно архив, которым готовили флешку 20 октября 2026 года; локальная копия сверена с официальным release asset. Внутри находится Homebrew Channel **0.7.3**. Изменений в сторонний архив не внесено. `Source code` и `corresponding-source.zip` предназначены для изучения/сборки и не заменяют USB-архив.

## Совместимость

Получение root и LG Gate проверялись на LG **SM8200PLA**, ПО **05.40.97**, webOS **4.10.2-29** (`goldilocks2-grampians`, поколение 4.5). Luna API сообщает SDK **4.10.0** — это другое поле, не версия прошивки. На 24 октября 2026 база [CanI.RootMy.TV](https://cani.rootmy.tv/) также относит эту прошивку к поддерживаемым DejaVuln. Для более новых прошивок, других моделей и других методов это не является подтверждением.

Перед действиями проверьте **свою модель и текущую прошивку** в CanI.RootMy.TV и прочитайте [инструкцию автора для v0.0.10](https://github.com/throwaway96/dejavuln-autoroot/blob/v0.0.10/README.md). Автор исключает модели 2016 года и старше; модели 2024 года и прошивки с исправленной уязвимостью требуют другого способа. Наличие уязвимости DejaVuln само по себе не означает совместимость LG Gate с моделью телевизора.

Получение root меняет защиту телевизора. Решение о применении принимает владелец устройства; эти действия не являются частью установки IPK. Сначала прочитайте ограничения upstream, особенно взаимодействие с приложением LG Developer Mode и обновлениями ПО.

## Подготовить флешку и запустить

Краткое изложение порядка из инструкции автора:

1. Используйте USB-накопитель с **одним разделом FAT32 или NTFS**. Сохраните важные данные заранее; форматировать накопитель с нужными файлами не требуется.
2. Распакуйте **USB-архив** в корень накопителя. `autoroot.sh` должен оказаться прямо в корне, без дополнительной внешней папки. Сохраните необычные имена вложенных папок и MP3-файла без изменений.
3. Подключите к ТВ только этот USB-накопитель. Откройте его в приложении «Музыка»/Media Player, войдите в папку с необычным именем и попробуйте воспроизвести MP3 из архива. Это специальный файл запуска; выполнять `autoroot.sh` на компьютере не нужно.
4. Ошибка воспроизведения MP3 ожидаема. Дождитесь уведомления **Rooting complete**, затем извлеките накопитель. Подробности и сообщения об ошибках находятся в upstream-инструкции; ошибка воспроизведения сама по себе не подтверждает получение root.
5. Если установлено приложение **LG Developer Mode**, удалите его до перезагрузки; не устанавливайте его на уже рутированный телевизор. Если Homebrew Channel не появился после успешного сообщения, следуйте разделу Troubleshooting автора.

При неудаче сначала изучите `autoroot.log` на флешке. Повторный запуск может потребовать удалить `autoroot.once` и/или перезагрузить ТВ — только после выяснения результата предыдущей попытки. Журнал может содержать сведения о вашем устройстве; не прикладывайте его к публичному репозиторию автоматически.

После появления Homebrew Channel продолжайте с [установки LG Gate из релиза](https://github.com/Donkiton/Lg-WebOS-launcher/blob/main/docs/QUICKSTART.md): включение SSH, свой ключ, IPK, Home и автозапуск.

## Происхождение и лицензии

DejaVuln Autoroot распространяется под **AGPL-3.0-or-later**, Homebrew Channel — под MIT с отдельными лицензиями входящих компонентов. В релизе рядом с неизменённым USB-архивом размещены `ROOT-TOOL-NOTICES.md`, текст AGPL и архив `dejavuln-autoroot-0.0.10-corresponding-source.zip`. В нём собраны исходники upstream и компонентов, а также рецепты/настройки их сборки. Точные адреса и SHA256 зафиксированы в `release/root-tool.json` репозитория и в companion-архиве. Автор USB-инструмента — throwaway96; уязвимость DejaVuln обнаружил Jacob Clayden; Homebrew Channel поддерживает webOS Homebrew Project.
