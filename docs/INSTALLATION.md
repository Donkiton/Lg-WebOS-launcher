# Установка LG Gate

[← На главную](../README.md)

> [!WARNING]
> **Проверено только на LG SM8200PLA.**
> ПО **05.40.97** · webOS **4.10.2 (поколение 4.5)** · Homebrew Channel **0.7.3**.
>
> **Для других моделей и версий совместимость не подтверждена.** Не устанавливайте IPK и не применяйте скрипты Home/автозапуска без отдельной проверки совместимости.

Перед установкой сверьте модель, версию ПО и webOS в сведениях о телевизоре, а также версию Homebrew Channel с конфигурацией выше. При несовпадении остановитесь: эта инструкция для вашей конфигурации не проверена.

Для полноценной работы нужны root-доступ и Homebrew Channel с root-сервисом. Исходный USB-архив DejaVuln Autoroot 0.0.10 приложен отдельно к [релизу v0.1.7](https://github.com/Donkiton/Lg-WebOS-launcher/releases/tag/v0.1.7); его происхождение, совместимость и порядок использования описаны в [ROOTING.md](ROOTING.md).

## Готовый комплект без сборки

Скачайте `lg-gate_0.1.7_install.zip` из релиза и следуйте [QUICKSTART.md](QUICKSTART.md). В ZIP уже есть проверенный IPK, скрипты Home/автозапуска, runtime и lock-файл зависимостей. Git и Python для установки из ZIP не нужны. Ниже сохранены полная настройка, сборка из исходников и история проверок.

## 1. Подготовить проект

Для предпросмотра нужен Node.js 18+. Для сборки используйте Node.js 20+; публикация проверена на Node.js 24.14.0. Для полного набора тестов нужен Python 3, доступный как `python` (либо задайте путь переменной `PYTHON`).

```powershell
git clone https://github.com/Donkiton/Lg-WebOS-launcher.git
cd Lg-WebOS-launcher
npm ci --ignore-scripts
npm test
```

Предпросмотр запускается командой `npm start` по адресу <http://127.0.0.1:4173>. Публичный каталог содержит шесть примеров приложений без индивидуальных дат установки. Запуск приложений и состояние сети в браузере имитируются; установленный на ТВ лаунчер получает данные самого телевизора.

## 2. Получить IPK

Готовый IPK доступен в [GitHub Releases](https://github.com/Donkiton/Lg-WebOS-launcher/releases/tag/v0.1.7) и в [папке dist](../dist/). Его также можно собрать из исходников:

```powershell
npm run package:tv
```

[LG Gate 0.1.7](../dist/org.lggate.launcher_0.1.7_all.ipk) содержит 35 файлов приложения, включая семь новых фонов, пять прежних и миниатюры. Панель выбора фона накладывается справа поверх лаунчера, сохраняя размер и положение часов и карточек. **По отдельной команде пользователя 0.1.7 установлена и проверена на ТВ 24 октября 2026.** Версия и SHA256 всех 35 файлов подтверждены; SHA256 пакета — `c0e26b12d0a30f2b296b2f784c16eadf8f1b037e1110f30ab5735cd30c72ca65`. Меню, WebP-фоны, сохранение выбора после перезапуска и сохранность настроек проверены. В конце восстановлено «Северное озеро».

Ранее установленный пакет: [LG Gate 0.1.6](../dist/org.lggate.launcher_0.1.6_all.ipk?raw=true), 16 файлов приложения, включая пять фонов. Сервер предпросмотра, тесты и данные личного телевизора в IPK не включаются. Предыдущие IPK в `dist/` сохранены как история версий. Контрольные суммы всех пакетов — в [SHA256SUMS.txt](../dist/SHA256SUMS.txt).

SHA256 пакета 0.1.6: `53de21ec0a9c30d57f007a62b3ff7d8f901fcc7ff847494495a45476e0d2b0a0`. В PowerShell его можно проверить командой `Get-FileHash -Algorithm SHA256 dist/org.lggate.launcher_0.1.6_all.ipk`.

Версия 0.1.6 и обновлённый runtime установлены на проверенном телевизоре 22 октября 2026 по отдельной команде пользователя. Приложение, его 16 файлов и runtime сверены с подготовленным комплектом. В настройках доступны ручной выбор пяти изображений и чёрный режим.

На устройстве проверены выбор и сохранение фона после полного завершения/нового запуска приложения, чёрный режим, Home из YouTube, Back и сохранность карточек/настроек. В конце оставлено «Северное озеро». Физическое отключение питания и холодное включение в этом этапе не проверялись.

## 3. Установить приложение на телевизор

Сначала подготовьте совместимый Homebrew Channel и root-доступ на своём телевизоре. В LG CLI настройте профиль устройства с именем `lg-tv`, используя свой адрес, порт и существующий способ SSH-аутентификации:

```powershell
npx --no-install ares-setup-device
npx --no-install ares-install --device lg-tv dist/org.lggate.launcher_0.1.7_all.ipk
npx --no-install ares-launch --device lg-tv org.lggate.launcher
```

Профиль LG CLI и SSH alias из следующего шага настраиваются отдельно. После запуска проверьте каталог, запуск приложений и управление пультом, прежде чем назначать новый Home. Node.js-сервер на ПК для работы установленного лаунчера не нужен.

## 4. Настроить Home и автозапуск

Скрипты используют OpenSSH `ssh` и `scp` с alias `lg-tv`, сохранённым ключом узла и входом по ключу без интерактивного запроса. Настройте их локально; адреса и ключи в репозиторий не добавляйте. На Windows конфигурация находится в `%USERPROFILE%/.ssh/config`. Замените `TV_IP`, `SSH_PORT` и путь к ключу своими значениями:

```sshconfig
Host lg-tv
    HostName TV_IP
    Port SSH_PORT
    User root
    IdentityFile ~/.ssh/lg-tv
    IdentitiesOnly yes
```

Проверьте отпечаток ключа узла при первом подключении и убедитесь, что команда `ssh lg-tv "id -u"` возвращает `0`. На проверенной прошивке runtime использует штатный `/usr/bin/python` 2.7 и пользовательские init.d hook Homebrew Channel.

```powershell
node scripts/manage-tv-home.js inspect
node scripts/manage-tv-home.js apply
node scripts/manage-tv-startup.js enable
node scripts/manage-tv-startup.js status
```

`apply` сохраняет исходное назначение Home на ТВ в `/var/lib/lg-gate/home-original.json`. `enable` устанавливает собственный hook и runtime; при первой установке включается также возврат Back. После холодного старта лаунчер открывается, когда готовы службы Homebrew; возможен начальный показ Live TV или последнего входа.

В версиях 0.1.4–0.1.5 runtime выбирал фон по времени включения. В 0.1.6 эта логика удалена: выбранное в настройках изображение подключается синхронно в CSS при каждом запуске. Служба сеансов остаётся для свежести каталога MSX; выбор фона от неё больше не зависит. Системная задержка запуска приложения и декодирования PNG всё ещё возможна и требует проверки на ТВ.

## 5. Проверить управление и откат

Стрелки перемещают фокус, OK запускает приложение, синяя кнопка открывает его действия. В каталоге для этого также есть режим «Настроить». Кнопка Home возвращает LG Gate. Внутри сторонних приложений Back сначала работает штатно; после окончательного выхода наблюдатель возвращает лаунчер.

Чтобы выключить только возврат Back:

```powershell
node scripts/manage-tv-startup.js back-disable
```

Для полного отката Home выполните команды в этом порядке **до удаления IPK**:

```powershell
node scripts/manage-tv-startup.js disable
node scripts/manage-tv-home.js restore
```

После успешного отката приложение можно удалить обычным способом или через `npx --no-install ares-install --device lg-tv --remove org.lggate.launcher`. Если отдельно применяли `manage-tv-optimizations.js apply`, его настройки возвращаются командой `node scripts/manage-tv-optimizations.js restore`.

## Дополнительные команды

| Команда | Действие |
| --- | --- |
| `node scripts/manage-tv-startup.js back-enable` | Включить возврат Back для установленного runtime |
| `node scripts/manage-tv-optimizations.js inspect` | Прочитать состояние рекламных переключателей и предзагрузки Assistant |
| `node scripts/manage-tv-optimizations.js apply` | Сохранить резервную копию и применить оптимизации рекламных переключателей и предзагрузки Assistant |
| `node scripts/manage-tv-optimizations.js restore` | Восстановить эти параметры |
| `node scripts/manage-tv-remote.js inspect` | Прочитать назначение отдельной кнопки IVI |
| `node scripts/manage-tv-remote.js apply` | Сохранить исходное правило и назначить кнопке IVI установленный YouTube |
| `node scripts/manage-tv-remote.js restore` | Вернуть штатное действие кнопки IVI |
| `node scripts/manage-tv-remote.js inspect zona` | Прочитать назначение кнопки Movies/Rakuten (USP) |
| `node scripts/manage-tv-remote.js apply zona` | Назначить кнопке Movies/Rakuten прямое открытие Zona в LG Gate 0.1.2–0.1.7 |
| `node scripts/manage-tv-remote.js restore zona` | Вернуть штатное действие кнопки Movies/Rakuten |
| `node scripts/sync-tv-catalog.js` | Заменить локальный каталог предпросмотра данными своего ТВ; такой снимок предназначен для личного использования |

Переназначение IVI применяется отдельно от установки IPK и только для проверенной конфигурации ТВ. Фильтр сохраняется в `/var/lib/lg-gate/ivi-youtube.js`, резервная копия — в `/var/lib/lg-gate/remote-ivi-original.json`. Правило записывается в постоянную настройку configd; отдельная программа на ПК для работы кнопки не нужна. После применения проверьте физической кнопкой запуск YouTube.

Для Zona сначала установите LG Gate 0.1.7: кнопка передаёт ему команду `shortcut: zona`, а лаунчер открывает карточку Zona из текущего каталога MSX. Адрес портала и настройки MSX не меняются. Фильтр — `/var/lib/lg-gate/usp-zona.js`, резервная копия — `/var/lib/lg-gate/remote-usp-original.json`. Назначения IVI и Zona применяются и восстанавливаются независимо.

## Обновление Wi-Fi 0.1.5

Кнопка Wi-Fi в 0.1.5 вызывает штатный экран LG: `com.palm.app.settings`, параметры `target: "WifiConnection"`. Список сетей, пароль и подключение обрабатывает телевизор. Если прямой переход отклонён, диалог предлагает кнопку общих настроек. В предпросмотре на ПК показано объяснение вместо системного окна. После возврата в LG Gate состояние сети обновляется.

Подготовка выполняется локально. Установка разрешена только после отдельной команды пользователя. По такой команде 22 октября 2026 установлен выпуск 0.1.5: версия, SHA256 пакета и всех 15 файлов подтверждены. Нажатие кнопки Wi-Fi на реальном лаунчере открывает системный список сетей; возврат Home проверен, карточки и настройки сохранены. Ввод пароля и смена сети не выполнялись.

## Подготовленное обновление 0.1.7

Текущий `scripts/install-prepared-tv.js` проверяет локальный комплект `.build/wallpaper-gallery-handoff/`: IPK 0.1.7 (35 файлов) и резерв прежней 0.1.6 (16 файлов). План `install-plan.json` содержит SHA256 обоих пакетов и всех файлов каждого. Резерв проверяется как полноценный IPK: control, манифест, отдельный точный состав, отсутствие установочных скриптов и ссылок, хеш каждого файла. Он совпадает с ранее проверенным выпуском 0.1.6. Старые комплекты `.build/wifi-handoff/` и `.build/manual-wallpaper-handoff/` сохранены. Подготовка выполнена без подключения к телевизору; последующая установка и native QA выполнены 24 октября 2026 по отдельной команде. Локальный комплект `.build/` не входит в репозиторий: в чистом клоне используйте IPK из `dist/` и LG CLI из шага 3.

Следующие проверки остаются полностью локальными и не создают SSH-подключение:

```powershell
node scripts/install-prepared-tv.js --dry-run
node scripts/install-prepared-tv.js --rollback --dry-run
```

Только после отдельной команды на установку и освобождения ТВ:

```powershell
node scripts/install-prepared-tv.js --execute --tv-free
```

После разрешения preflight проверит root, модель, прошивку, SDK 4.10.0 (отдельное поле `getSystemInfo`), Homebrew, текущую версию LG Gate и wake marker текущего включения. Установщик сверит переданный IPK, затем версию и SHA256 всех 35 установленных файлов до запуска. Он обновляет только приложение: Home, runtime, автозапуск, назначения кнопок и системные настройки не меняет. Существующие ключи избранного, порядка, оформления и выбора фона сохранены; прежние фоны доступны во вкладке «Классические». На реальном ТВ проверены загрузка всех новых изображений, управление пультом, отмена предпросмотра и сохранение выбранного фона/чёрного режима после полного завершения и нового запуска. Точное время декодирования и холодное включение питания не измерялись.

Откат только пакета к резервному 0.1.6, также после команды пользователя:

```powershell
node scripts/install-prepared-tv.js --rollback --execute --tv-free
```

Откат проверяет резерв, переданные байты, версию и все 16 файлов до запуска. Понижение версии на реальном ТВ ещё не проверялось: при отказе установки остановитесь, сохранив сообщение об ошибке; удаление приложения с его данными не входит в процедуру. Для установки опубликованной версии из чистого клона остаётся LG CLI из шага 3.

Версия 0.1.5 проверена 377 тестами, IPK собран официальным CLI 3.2.6. Проверки на ТВ описаны в [истории разработки](DEVELOPMENT.md). Подготовка 0.1.5 выполнялась без подключения к ТВ; её последующая установка выполнена по отдельной команде пользователя. Локальные снимки, журналы, резервные копии и каталоги `.build/` / `%TEMP%` не публикуются. [DESIGN.md](../DESIGN.md) сохраняет историю проектирования.
