# Подготовка GitHub Release

Пользователю телевизора достаточно [установочного ZIP](QUICKSTART.md). Эта инструкция предназначена для сопровождающего репозитория.

## Подготовить артефакты

Нужны Node.js 20+, Python 3 и зависимости из lock-файла:

```powershell
npm ci --ignore-scripts
npm test
npm run release:prepare
```

Последняя команда работает локально без сети и подключения к телевизору. Она проверяет SHA256 текущего IPK из `dist/`, читает его control/data-архивы, отвергает лишние файлы/ссылки/установочные скрипты и сверяет все 35 файлов с подготовленными исходниками. Сохраняются именно байты проверенного на ТВ пакета 0.1.7. Установочный ZIP создаётся из явного списка; локальные ключи, профили устройств, журналы, снимки каталога, `node_modules` и прежние IPK в него не входят.

Для полного релиза, включая исходный USB-архив и исходники сторонних компонентов:

```powershell
npm run release:prepare -- --with-root-tool
```

Этот флаг разрешает скачивание файлов, зафиксированных URL и SHA256 в `release/root-tool.json`. Каждое скачивание проверяется; архивы не запускаются и не устанавливаются. Валидный кеш в `.build/release-cache/` используется повторно; повреждённый кеш вызывает ошибку. Приложите полученные лицензии, notices и companion-архив исходников вместе с USB-архивом.

Результат находится в `.build/releases/v0.1.7/`:

| Файл | Назначение |
| --- | --- |
| `org.lggate.launcher_0.1.7_all.ipk` | Проверенное приложение для ТВ |
| `lg-gate_0.1.7_install.zip` | IPK, инструменты Home/автозапуска и инструкции |
| `INSTALLATION.md`, `ROOTING.md` | Инструкции, доступные без распаковки |
| `LG-Gate-LICENSE.txt` | Полные условия использования оригинальных материалов LG Gate; копия есть и внутри ZIP |
| `dejavuln-autoroot-0.0.10.zip` | Неизменённый USB-архив upstream |
| `dejavuln-autoroot-AGPL-3.0.txt`, `ROOT-TOOL-NOTICES.md` | Лицензия и происхождение |
| `dejavuln-autoroot-0.0.10-corresponding-source.zip` | Исходники и рецепты upstream-компонентов |
| `release-manifest.json` | SHA256 каждого файла приложения и release asset |
| `SHA256SUMS.txt` | SHA256 всех остальных файлов релиза |

Проверка CRC, имён и содержимого ZIP выполняется при сборке. Фиксированные даты и права записей делают установочный ZIP воспроизводимым при одинаковых входных файлах и версии Python/zlib. ZIP не содержит времени сборки или локальных абсолютных путей.

## Изменение приложения

`npm run package:tv` собирает новый IPK официальным `@webos-tools/cli@3.2.6`. Для изменения версии сначала синхронизируйте `appinfo.json`, `package.json`/lock, строгие манифесты упаковщика/установщика и тесты. Обновите контрольные суммы и задокументируйте реально выполненную проверку на ТВ. Новый пакет не следует объявлять тем же проверенным 0.1.7: его SHA256 и история проверки должны соответствовать действительным байтам.

## Опубликовать

Изменения кода и инструкции сначала проходят PR в `main`. После тестов и слияния можно запустить GitHub Actions **«Опубликовать релиз»** вручную из `main`, указав текущую версию. Workflow собирает полный комплект, а затем создаёт новый Release на точном commit workflow; уже существующий релиз не перезаписывает.

При локальной публикации используйте GitHub CLI: создайте релиз с тегом `v0.1.7`, точным merge commit и описанием `release/NOTES-v0.1.7.md`, загрузив **все** файлы из выходной папки. После загрузки скачайте assets в отдельную папку и сравните SHA256. Не отправляйте `.build/` в Git.

Сборка и публикация не включают SSH-подключение к телевизору. Факт публикации не считается новой проверкой установки на реальном устройстве.

В описании релиза укажите лицензию LG Gate и ссылку на соответствующий исходный архив тега. Автоматические архивы `Source code` GitHub содержат исходники LG Gate; companion-архив DejaVuln относится к отдельному стороннему инструменту.
