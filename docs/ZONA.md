# Zona: каталог Android и дополнительные источники

Исходники установленного модуля `zona-providers-20261115.1`. Каталог, поиск, карточки, сезоны и точные эпизоды используют Android API. Загрузчик передаёт источники существующим обработчикам и независимо запрашивает Kinogo, HDrezka и Cdnvideohub. Готовый ответ одного поставщика не ждёт остальных. Ошибки необязательного поставщика не отменяют остальные результаты; запросы разных эпизодов изолированы.

Новый обработчик Cdnvideohub сохраняет озвучки и качества. Локальный relay передаёт заголовки поставщика, потоково обслуживает MP4/Range и переписывает HLS. Проверка TLS включена, используются публичные CA. Адреса ограничены CDN поставщика, наружу выдаются непрозрачные токены. Реестр ограничен 4096 ссылками / 4 МиБ. Слишком большой HLS отклоняется атомарно: успешный плейлист не содержит ссылок, вытесненных при его обработке.

## Состав и сборка исходников

`tv/zona-*.js` — собственные модули и преобразования интерфейса. Имена этих файлов для развёртывания перечислены в `tv/zona-runtime.json`. `tv/zona-support/` содержит прежние зависимости службы, переносимый transport и публичные CA. Лицензии Long и Pako сохранены рядом с библиотеками; они не заменяются лицензией проекта. `portable/runtime-ir.json` — статические инструкции транспорта, а не данные аккаунта.

Исходный внешний браузерный loader не публикуется в Git. Сборщик скачивает его с исходного адреса и принимает только проверенный SHA256. Изменившийся upstream требует отдельной проверки; автоматически принимать его нельзя.

```powershell
node scripts/prepare-zona-runtime.js
# Либо полностью локально, с сохранённым проверенным loader:
node scripts/prepare-zona-runtime.js --loader C:/path/to/loader-original.js
```

Результат: `.build/zona-runtime/zona-providers-20261115.1/`, 29 файлов с проверенными SHA256. Сборщик ничего не устанавливает на ТВ. На ТВ используется Node 0.12.2; браузерный loader исполняется браузером, а не Node. Для просмотра после установки ПК не требуется.

Установщик конкретного телевизора, резервные копии, SSH-настройки, журналы просмотра, APK, бинарные инструменты и данные устройства остаются локальными в `.build/`; они не входят в этот PR. Этот набор исходников не заменяет подготовленный для устройства установщик. Его использование и установка — отдельные операции.

## Проверки и ограничения

Полный установленный артефакт прошёл на ПК 687 тестов проекта, 43 интеграционные и 116 проверок установщика. Все 23 Node-модуля проверены настоящим Node 0.12.2. В отдельной ветке публикуются только изменения Zona; остальные локальные изменения интерфейса LG Gate не включены, поэтому количество тестов этой ветки отличается.

`npm test` проверяет проект и новые модули без обращений к ТВ. Дополнительные проверки старого runtime используют `ZONA_NODE012` либо локальный `.build/zona-source-lab/autonomy/runtime/node-v0.12.2-x64.exe`; при отсутствии бинарника явно пропускаются. Проверка полного внешнего player bundle также необязательна и использует локально сохранённый файл; основные проверки работают на небольших фиксированных фрагментах.

На ПК подтверждены несколько озвучек Cdnvideohub в одном качестве, MP4 Range206 через интегрированную службу и декодирование H264/AAC обычным клиентом без специальных заголовков. У некоторых произведений этот источник возвращает пустой список. HDrezka реализован и проверен на фикстурах, но его живой сервер давал timeout; реальное получение его озвучек не подтверждено. Turbo не реализован. Полное равенство всем источникам Android не заявляется.

Версия установлена подготовленным установщиком, проверены 29 файлов и готовность службы. Пользователь подтвердил работу нашей Zona. Краткая read-only проверка после просмотра: stderr пуст, служба готова; отмечен таймаут необязательного HDrezka. Отдельное приложение Zona Legacy не изменяется этим модулем.
