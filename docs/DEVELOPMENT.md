# Технические заметки и история проверок

[← На главную](../README.md) · [Установка](INSTALLATION.md)

Исторический журнал разработки. Числа тестов, контрольные суммы и описания установки ниже относятся к соответствующим этапам. Актуальный IPK и SHA256 находятся в [dist](../dist/). Упомянутые локальные журналы и снимки не публикуются.

Домашний экран по выбранному макету: фон, часы, карточки приложений, экран всех приложений и настройки. Доступны браузерный предпросмотр и приложение LG Gate на LG SM8200PLA. На телевизоре Home назначен на LG Gate, включён автозапуск через существующий Homebrew Channel. Подробности проверки и отката ниже.

## Запуск на компьютере

Нужен Node.js 18 или новее. Дополнительные пакеты устанавливать не требуется.

```powershell
npm start
```

Откройте [предпросмотр](http://127.0.0.1:4173) в браузере. Для остановки сервера нажмите `Ctrl+C` в терминале. При необходимости другой порт можно задать через переменную окружения `PORT`.

Сервер слушает только `127.0.0.1`, поэтому предпросмотр доступен на этом компьютере. Процесс Node.js нужен лишь для предпросмотра на ПК. Установленный IPK содержит собственные ресурсы и работает на телевизоре без этого сервера и без SSH-подключения с ПК.

## Управление

- Стрелки — перемещение между карточками и элементами интерфейса.
- Короткое `Enter` / OK — открыть приложение.
- В «Все приложения» кнопка **Настроить** включает режим, в котором короткое OK на карточке открывает её действия. **Готово** или «Назад» возвращает обычный запуск.
- **Синяя кнопка пульта** — действия выбранного приложения на главном экране или в каталоге (`keyCode 406`). На ПК также работают `M` и правый клик.
- Удержание `Enter` / кнопки мыши (700 мс) — меню приложения, если платформа передаёт фактические down/up. В записанном режиме физического OK этого телевизора webOS передаёт даже удержание как короткий импульс; для него используйте два способа выше.
- `Escape` или `Backspace` — возврат.
- `Home` или `H` на клавиатуре ПК — возврат на домашний экран прототипа. На настроенном ТВ кнопка Home открывает главный экран LG Gate.
- `F` — полноэкранный режим. `Escape` также позволяет выйти из полноэкранного режима браузера.
- Мышь — наведение и выбор элементов.

В меню приложения доступны добавление / удаление карточки с главного экрана и перестановка. На главном экране до шести приложений. Если все шесть мест заняты, добавление сразу предлагает выбрать заменяемую карточку. Само приложение при этом остаётся в каталоге. Номер на карточке каталога обозначает её место на главном.

«Все приложения» открываются кнопкой с сеткой вверху справа, рядом с Wi-Fi и настройками. Нижний ряд содержит только выбранные приложения. Стрелки влево / вправо перемещают фокус между тремя верхними кнопками; вниз возвращает к выбранной карточке. Кнопка каталога доступна и при пустом главном экране.

Каталог разбит на страницы по 18 карточек: три ряда по шесть. Стрелка вправо на правом краю строки открывает следующую страницу, влево на левом краю — предыдущую. Внизу доступны кнопки страниц и счётчик. Неполная последняя страница показывает только существующие приложения. Возврат из запуска или меню сохраняет выбранное приложение и страницу.

Начало первой страницы повторяет приложения главного экрана в их текущем порядке. Остальные сохраняют отдельный базовый порядок: при первом чтении — порядок, полученный от системы, после этого новые приложения добавляются в конец. Исторические даты установки не предполагаются. Закрепление не меняет базовый порядок; после снятия с главного приложение возвращается на своё место среди остальных. Порядок хранится на устройстве отдельно от избранного.

Подсказки про правый клик и клавиатуру показываются только в браузере. На ТВ пояснение мест внизу отсутствует; подсказки OK в каталоге показываются при включённом параметре «Подсказки управления». В публичном браузерном предпросмотре показаны шесть общих примеров; локально каталог можно заменить собственным снимком по SSH. На телевизоре установленные приложения определяются из текущего ответа webOS; поддерживаемые ярлыки MSX дополняют этот список.

При перестановке стрелки влево / вправо на карточках сдвигают выбранное приложение. Вниз переводит фокус на «Сохранить»; в нижнем ряду влево / вправо выбирают кнопки, не меняя порядок. OK нажимает выбранную кнопку; вверх возвращает к перемещаемой карточке. «Отмена» и «Назад» / Escape закрывают черновик без сохранения. Состав карточек, порядок и настройки сохраняются локально в текущем браузере. Они доступны после перезапуска предпросмотра, пока не очищены данные сайта; в другом браузере или на другом порту данные отдельные. Очистка главного экрана не приводит к повторному автоматическому закреплению приложений.

## Интеграция с webOS

Интерфейс работает через `platform.js`: приложения, сеть, входы и системные действия отделены от экранов. В браузере используется `preview-catalog.js` с демонстрационным каталогом либо собственным локальным снимком и значки в `assets/tv-apps/`; сеть и входы честно недоступны. Снимок и живой ответ ТВ проходят одну нормализацию. В установленном приложении webOS адаптер использует PalmServiceBridge и Luna-службы:

- каталог: `com.webos.applicationManager/listLaunchPoints`; при отказе доступа — тот же фиксированный запрос через существующий `org.webosbrew.hbchannel.service/exec`;
- запуск приложения: `com.webos.applicationManager/launch` с реальным ID из каталога;
- сеть: `com.palm.connectionmanager/getStatus`;
- входы: `com.webos.service.eim/getAllInputStatus`, без фиксированного списка HDMI;
- настройки LG: запуск `com.palm.app.settings` из пункта «Настройки телевизора».

Отмена выбора входа во время ожидания данных предотвращает последующую отправку переключения. Уже отправленный системный запуск отменить нельзя.

В установленном приложении список запрашивается при запуске и обновляется при возврате фокуса / видимости и открытии каталога с ограничением частоты. Новые и удалённые приложения учитываются автоматически. На проверенной прошивке 05.40.97 прямой доступ к каталогу запрещён, а запрос через установленный Homebrew Channel 0.7.3 работает. Для живого каталога и значков нужен работающий root-сервис Homebrew; открытый SSH для повседневного использования не требуется. На старте сначала показываются сохранённые главные карточки с этого телевизора, затем они сверяются с живым ответом. Ошибка службы не считается подтверждением удаления приложения. Сам LG Gate исключается из своего каталога.

Прямое чтение значков других приложений через `file://` на ТВ запрещено. Адаптер получает нужные PNG пакетами до шести через Homebrew: только пути внутри каталогов приложений, строгая проверка пути, отдельные shell-кавычки и ограничение 256 КиБ на файл. Первыми обслуживаются текущие главные приложения, затем видимая страница каталога. Встроенное оформление YouTube, Okko, RUTUBE, ivi и Zona не требует чтения PNG. До получения картинки карточка показывает название; запрещённый `file://` запрос не отправляется. Полученные изображения используются как data URL. Сбой загрузки значка оставляет название и возможность запуска приложения.

Выбор главных приложений и их порядок остаются в прежнем хранилище избранного. Дополнительный кэш `lg-gate-home-cards-v1-webos` содержит до шести выбранных карточек, включая доступные PNG; размер JSON ограничен 1 048 576 символами. При переполнении в первую очередь сохраняются метаданные. Кэш не определяет порядок и не возвращает ранее удалённые закрепления. Добавление, замена, снятие и сохранённая перестановка обновляют его; отмена черновика не записывает изменения. При обновлении из пяти мест в шесть прежний выбор сохраняется без автоматического заполнения нового места.

Список native-приложений публикуется сразу после ответа системы. PNG и чтение MSX идут независимо от его отображения. Каждый источник отдельно отмечает полноту: временный сбой или ещё не завершённый запрос не подтверждают удаление. Обновления, пришедшие во время меню, перестановки или нажатия, откладываются; загрузка картинки сохраняет сам элемент кнопки и фокус. Нативные PNG перепроверяются после успешного обновления каталога, в том числе при прежнем пути файла.

Сам браузерный предпросмотр работает с сохранённым снимком и не обращается к телевизору. На ТВ установлен пакет `org.lggate.launcher`. Текущее назначение Home и собственный hook автозапуска описаны ниже; физическая кнопка настроек пульта не перехватывается. Пользователь проверил основной запуск и настройки, выбрал режим без анимации из-за задержек на плавных режимах. Физическое отключение питания из розетки ещё не проверено.

### Приложения Media Station X

Если установлен `de.benzac.msx`, LG Gate дополнительно читает его текущую настройку старта. Для проверенной webOS 4.5 используется фиксированный запрос SQLite с `mode=ro` через существующий Homebrew Channel: только поля `start`, `server`, `server_secure`, `start_name`, `start_version`. ID устройства, токены и история не читаются; база и установленный MSX не изменяются.

Настройка указывает на публичный JSON-каталог. Из его верхнего уровня `items`, `pages[].items` и `menu[].data` импортируются поддерживаемые ярлыки, без обхода вложенных медиатек и фильмов. Модуль `msx-catalog.js` распознаёт HTTP(S)-действия `link:`, `link:replace:`, `link:window:`, `content:` и `menu:`. Адреса, названия и значки приходят из конфигурации; Zona не зафиксирована в коде. Сложные interaction-порталы, защищённые серверные списки и произвольные команды MSX не импортируются. Это не универсальное извлечение любого внутреннего меню MSX.

Виртуальные карточки появляются в **«Все приложения» LG Gate** и поддерживают обычное закрепление, замену и перестановку. Они не устанавливают отдельные приложения в системный каталог LG. Их стабильный ID основан на действии MSX, поэтому переименование или изменение порядка в источнике не сбрасывает закрепление. Последний успешный список хранится локально и используется при временной ошибке сети или чтения настроек. Успешный пустой ответ, сброс источника или удаление MSX убирают его карточки; смена источника не подставляет старый каталог.

Небольшая отдельная запись источника защищает восстановление MSX после очистки или смены портала, даже если большой список не поместился в хранилище. Для произвольного удалённого значка MSX сохраняется URL; его доступность зависит от сети и HTTP-кэша движка. Встроенное оформление текущей Zona от этого не зависит.

`link:` открывается в полноэкранном iframe внутри LG Gate с передачей фокуса пульту. `content:` / `menu:` используют официальный веб-клиент MSX с параметром `start`; `link:window:` открывает системный браузер. Неподтверждённые параметры запуска установленному MSX не передаются. Повторный запуск LG Gate через webOS возвращает главный экран и удаляет iframe вместе с плеером. Вложенный сайт управляет собственным «Назад»; совместимость каждого портала и воспроизведение следует проверять на ТВ.

Проверенная текущая конфигурация MSX содержит один ярлык — Zona. Его JSON предоставляет прямой адрес автономного веб-приложения. Документация: [MSX Actions](https://msx.benzac.de/wiki/index.php?title=Actions), [Start Object](https://msx.benzac.de/wiki/index.php?title=Start_Object), [Menu Item Object](https://msx.benzac.de/wiki/index.php?title=Menu_Item_Object), [URL Parameters — для веб-версии](https://msx.benzac.de/wiki/index.php?title=URL_Parameters).

## Сборка IPK

Для сборки нужны Node.js 20+ и закреплённый официальный `@webos-tools/cli@3.2.6`:

```powershell
npm ci --ignore-scripts
npm test
npm run package:tv
```

Результат — `dist/org.lggate.launcher_0.1.0_all.ipk`. Скрипт сборки ничего не устанавливает и не подключается к телевизору. В staging `.build/tv-app` попадают только одиннадцать разрешённых файлов: манифест, HTML/CSS/JS, фон и собственные значки лаунчера. `portal.html` служит локальной точкой запуска/возврата встроенных приложений. Браузерный снимок, значки других приложений, сервер, тесты и документация исключены. Упаковка выполняется официальным CLI без минификации. Предупреждение CLI об отсутствии `requiredACG` не помешало проверке манифеста и установке на webOS 4.5; дополнительные привилегии в манифест не добавлялись.

### Обновление управления Magic Remote

При физическом удержании OK 2–3 секунды записана последовательность `keydown 13` → `keyup 13` с интервалом 126,53 мс; mouse-событий в этой записи нет. Такой DOM-сигнал не позволяет отличить реальное удержание от короткого нажатия. Это наблюдение относится к текущему пути ввода, а не доказывает ограничение самого пульта или всех системных приложений. Проверка двух evdev-устройств M-RCU не дала событий и не подтверждает доступность/невозможность удержания на root-уровне. Постоянный перехват ввода не устанавливался.

Исправлены независимые дефекты обработчиков: ранний click до отпускания не запускает приложение; дубли mouse/Enter не перезапускают таймер; сопровождающий click после открытия меню не нажимает его первый пункт; отмена, уход фокуса и запоздавший timer обрабатываются явно. Добавлены режим **Настроить** и **синяя кнопка** для доступа к меню без удержания. Выбор режима анимации и избранное при обновлении сохранены.

В установленном приложении проверены через отладочный ввод: вход в режим настройки стрелками/OK, открытие действий коротким OK, выбор замены среди пяти занятых мест, отмена и выход из режима, синяя кнопка, удержание мыши и подавление завершающего click. Пользователь затем проверил новые способы физическим пультом и подтвердил: работают, такой вариант устраивает. Справка ТВ и подсказки обновлены под «Настроить» / синюю кнопку; обещание меню через удержание OK на ТВ убрано. `tests/remote-input.test.js` проверяет production-обработчики на повторах, смешанном вводе, смене DOM и отменах; общий набор — 85 тестов. Сведения о двух режимах Magic Remote и коде синей кнопки: [LG Magic Remote](https://webostv.developer.lge.com/develop/guides/magic-remote).

В исходном системном каталоге отдельной Zona нет: установлен Media Station X. До добавления импорта MSX прежняя тестовая карточка Zona была заменена на реальную карточку MSX. Старые выбранные приложения и порядок переносились на реальные ID по известным названиям брендов, без полного сброса настроек. Для знакомых сервисов сохраняется оформление согласованного макета, остальные используют значок с телевизора и фактическое название. Если изображение недоступно, название остаётся видимым.

## Back: возврат из приложений — 21 октября 2026

На этой прошивке Home и завершение приложения используют разные системные пути. Фактическая трасса YouTube: нажатия Back сначала работают внутри приложения, затем YouTube уходит в фон со статусом `normal`, а webOS запускает `com.webos.app.livetv`. События закрытия при этом может не быть. В `/etc/lsm/default.json` включён `ysm.launchLastInputAppAfterClosing`; `/usr/lib/qt5/qml/YSM/compositor.js` также выбирает последний вход при ряде способов закрытия. Назначение `general.defaultApps.home` само по себе не заменяет эти пути. LG Gate при запуске YouTube может выгружаться с причиной `memoryReclaim`, поэтому рассчитывать на сохранившееся предыдущее окно нельзя. [Документация LG о разных способах обработки Back](https://webostv.developer.lge.com/develop/guides/back-button).

Существующий Python runtime дополнен наблюдателем, включаемым файлом `/var/lib/lg-gate/back-enabled`. Он пассивно читает `EV_KEY` только устройств пульта, определённых по именам в `/proc/bus/input/devices`. Back — Linux-код 412, а не DOM-код 461. Устройства открываются только для чтения, без `EVIOCGRAB`; штатная доставка кнопок приложению сохраняется. События пульта и содержимое приложений в журнал не записываются. [Пример совместимого пассивного чтения evdev](https://github.com/rorygallagher2024/glasshouse/blob/main/server/lib/remotebuttons.py).

Ожидание возврата начинается после Back в известном установленном приложении или его обычного закрытия. Стрелки и OK сохраняют возможность подтвердить выход; другое приложение, системное окно, Home, выбор входа и уход питания отменяют ожидание. Список входов определяется через EIM, без фиксированного количества HDMI. Только при устойчивом переходе к входу/штатному Home повторно проверяются foreground, питание, назначение Home и наличие LG Gate, затем выполняется одна попытка его запуска. Внутренний Back и Back на главном экране LG Gate не переназначаются. При таком способе возврата возможен короткий показ штатного входа, пока LG Gate заново запускается.

Ожидание после Back ограничено 60 секундами, после обычного закрытия — 3 секундами. Неоднозначные окна, потеря подписки или отсутствие подтверждения не приводят к принудительному запуску. Периодическая проверка каталога ограничена 0,5 секунды на запрос, откладывается во время ожидания выхода и при ошибке сохраняет последние проверенные данные. Явный выбор источника остаётся доступен.

Установщик обновляет только собственный runtime/hook, сверяет SHA256, проверяет импорт и синтаксис реальным Python 2.7 телевизора. Повторное обновление сохраняет ранее отключённый режим Back. Обновление IPK приложения для этого этапа не требуется.

При отдельном отключении наблюдателя те же три Back в YouTube оставляют HDMI на экране, а после включения возвращают лаунчер. Повторное включение на уже открытом HDMI само по себе его не закрывает.

Скрипт выполняет только чтение: запрос списка launchPoints и копирование PNG-значков с телевизора на ПК. Он сохраняет ID, названия, пути локальных значков, цвет и время установки, если они сообщены системой. Проверка сохранённого SSH-ключа узла остаётся включённой. При ошибке чтения прежний снимок сохраняется. Для отображения нового снимка обновите страницу предпросмотра. На самом ТВ этот снимок не является источником приложений.

## Проверки

`npm test` запускает встроенные Node-тесты правил карточек, порядка, страниц и адаптера: размеры каталогов 0/1/15/16/30/31/137, навигация на границах, возврат в базовый порядок после снятия избранного, реальные ID, неизвестные статусы, отказ служб, таймауты и отмена. Для интерфейса дополнительно проверяются короткое / длинное OK, перелистывание, запуск и возврат со второй страницы, замена при заполненном главном экране, синхронизация первой строки с главным экраном, сохранение / отмена порядка и возврат фокуса.
